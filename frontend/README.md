# Envoy Frontend

## Run

```bash
npm install
npm run dev
```

## Pages
- `/` Dashboard
- `/projects` Projects
- `/upload` Upload
- `/tasks` Tasks
- `/semantic-units` Semantic Units
- `/artifacts` Artifacts
- `/trace` Trace
- `/train-exports` Train Exports
- `/train-exports/[record_id]` Export Record Detail

## Capabilities
- 任务目录预览
- 一键打开输出目录
- 导出历史记录展示
- 导出结果路径展示
- 导出历史详情查看
